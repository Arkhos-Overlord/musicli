v0.2.0 what's new
  • 🎨 Cover art — album art renders as ANSI half-blocks at full color
  • 🎨 6 retro themes — Amber, Synthwave, CRT Green, IBM 5151, Matrix Rain, Cyberpunk
  • 📊 Stereo FFT VU meter — per-channel spectrum bars (L/R)

CRT Amber VGA Synthwave CRT Green IBM 5151 Matrix Rain Cyberpunk

Cycle with t

Install

$ pip install musicli
$ cd ~/Music
$ musicli
Now playing: 6 themes, cover art, stereo VU

Features

🎵
Format Support
MP3, FLAC, WAV with automatic metadata extraction and cover art
🎚️
3-Band Parametric EQ
RBJ biquad filters: Low-shelf 150Hz, Peaking 1kHz, High-shelf 8kHz
📊
Stereo Visualizer
Per-channel FFT spectrum (L/R) + waveform with position marker
🎨
6 Retro Themes
Amber, Synthwave, Green, IBM 5151, Matrix, Cyberpunk — cycle live
🖼️
Cover Art
Album art extracted from tags and rendered as ANSI half-blocks
⏭️
Gapless + Crossfade
Zero-gap transitions with smooth crossfade blending
📝
Synced Lyrics
Auto-fetched LRC lyrics highlight current line in real-time
🔊
ReplayGain
Normalized loudness via embedded tags or RMS fallback
📋
Play Queue
Add, reorder, and clear tracks on the fly
❓
Help Overlay
Press ? to view all keybindings without pausing playback

Controls

KeyAction
↑ ↓ j kNavigate library
EnterPlay selected track
SpacePlay / Pause
n / pNext / Previous track
← →Seek -10s / +10s
+ / -Volume up / down
1 2 3EQ boost +2dB (Bass/Mid/Treble)
! @ #EQ cut -2dB
rCycle repeat mode (off → track → album)
sToggle shuffle
cToggle crossfade
tCycle theme (6 themes)
wCycle waveform style
/Search library
aAdd current track to queue
dRemove current from queue
[ ]Move queue item
xClear queue
?Toggle help overlay
qQuit (saves state)

Audio Pipeline

File → miniaudio → ReplayGain → 3-Band EQ → Volume → TPDF Dither → Speaker ↓ FFT L+R → Stereo Visualizer
