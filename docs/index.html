Install

$ pip install musicli
$ cd ~/Music
$ musicli

Features

🎵
Format Support
MP3, FLAC, WAV with automatic metadata extraction
🎚️
3-Band Parametric EQ
RBJ biquad filters: Low-shelf 150Hz, Peaking 1kHz, High-shelf 8kHz
📊
Real-time Visualizer
FFT spectrum bars + waveform display with position marker
🎨
Retro Themes
CRT Amber and VGA Synthwave — full terminal aesthetic
⏭️
Gapless + Crossfade
Zero-gap transitions with smooth crossfade blending
📝
Synced Lyrics
Auto-fetched LRC lyrics highlight current line in real-time
🔊
ReplayGain
Normalized loudness via embedded tags or RMS fallback
📋
Play Queue
Add, reorder, and clear tracks on the fly

Controls

Audio Pipeline

File → miniaudio → ReplayGain → 3-Band EQ → Volume → TPDF Dither → Speaker ↓ FFT → Visualizer
